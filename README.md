# IMOCE donation website

Статичний багатомовний сайт для HOSTiQ; робоча гілка develop. Runtime: HTML/CSS/JS, без Node.js, PHP або бази даних на сервері.

## Поточна оплата

Основні кнопки ведуть на https://imoce.givingfuel.com/turkana-schools-support у цій самій вкладці. Платіжного iframe на сторінці немає: після повідомлених помилок вбудованої оплати використовується hosted checkout. GivingFuel відповідає за суму/регулярність, оплату, банківську автентифікацію та квитанцію. Наша сторінка не читає реквізитів, не надсилає платіж і не показує власного підтвердження успіху.

Докладна діагностика, межі перевірки, інструкція оновлення HOSTiQ та звернення до провайдера: [PAYMENT-INCIDENT.md](PAYMENT-INCIDENT.md). Якщо кошти вже списано, не робіть автоматично повторний внесок: перевірте квитанцію/кабінет або зверніться до IMOCE. Прямий checkout прибирає iframe-контекст, але не гарантує схвалення кожної транзакції.

Venmo, PayPal, Cash App та соцмережі збережені. На HOSTiQ нічого автоматично не завантажується.

## Редагування

- Шаблон: templates/index.html. Переклади: translations/en.json, uk.json, ru.json.
- Англійська сторінка: коренева та /en/. Українська: /uk/. Російська: /ru/.
- Генерація: `python3 scripts/build_languages.py`.
- Повний архів HOSTiQ: `python3 scripts/package.py` → dist/imoce-donation-demo.zip (історична назва).
- Логотипи/зображення локальні в assets. Хедер і footer ведуть на https://imoce.org/. Назва: International Ministry of Charity.
- Юридичні сторінки privacy.html, terms.html, donation-policy.html у корені й мовних папках містять англійський текст власника; навігація перекладена. Тексти редагуються в templates/*-body.html.
- Не редагуйте лише згенерований index.html: спочатку внесіть зміни до шаблону, інакше вони загубляться під час генерації.

## Локальна перевірка

У каталозі проєкту: `python3 -m http.server 8000 --bind 127.0.0.1`.

За наявності Playwright і Chromium:

```sh
node tests/checkout.cjs
node tests/smoke.cjs
node tests/languages.cjs
node tests/links.cjs
node tests/legal.cjs
```

CHROMIUM_PATH перевизначає /usr/bin/chromium. Зовнішня навігація в тестах перехоплюється: це перевірка нашого інтерфейсу, не реальна оплата. TLS-перевірка не вимикається. Активного iframe більше немає; старі бібліотечні файли assets/vendor залишені невикористаними й не потрібні для оплати.

## HOSTiQ

Зробіть резервну копію наявного каталогу donate. Для цього виправлення використайте dist/imoce-payment-fix.zip, для повного сайту — dist/imoce-donation-demo.zip. Архів виправлення створюється командою `python3 scripts/package.py --payment-fix`. Розпаковуйте вміст у корінь каталогу donate без зайвої вкладеної папки. Не завантажуйте .git, templates, translations, scripts, tests, artifacts або службові markdown-документи. Використовуйте HTTPS; очистьте кеш і перевірте всі мовні версії. Реальний тестовий внесок — лише за окремим дозволом власника. Не змінюйте одночасно налаштування платіжного провайдера без перевірки.

На desktop (>760 px) нижній повторний блок GivingFuel прихований: основна кнопка залишається в hero. На мобільних екранах hero-картка прихована, а нижній блок із кнопкою збережений. На кожній ширині доступна рівно одна основна кнопка GivingFuel. Для цього CSS-виправлення на HOSTiQ достатньо замінити styles.css.
