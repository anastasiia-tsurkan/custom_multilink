# IMOCE — сторінка донатів (демоверсія)

Статичний сайт без збірки та серверних залежностей. Робоча гілка: `develop`.

## Локальний перегляд

У каталозі проєкту виконайте `python3 -m http.server 8000 --bind 127.0.0.1`.
Відкрийте локальний порт 8000 у своєму браузері. Для роботи сайту достатньо будь-якого статичного HTTP-сервера.

## Що працює

- Адаптивна верстка за настільним і мобільним макетами.
- Векторні іконки блоку довіри в `assets/icons/`, відтворені за наданими зразками: щит, рукостискання, академічна шапочка та око.
- Вибір місячного / одноразового внеску, суми та власної суми ($1–$1,000,000, до двох десяткових знаків).
- Перевірка суми браузером, демодіалог, закриття Escape і повернення фокусу.
- Venmo, PayPal, Cash App і соціальні посилання відкривають надані власником адреси в новій вкладці. Лише юридичні кнопки залишаються заглушками.
- Іконки Instagram, Facebook, YouTube та сайту — локальні SVG, відтворені за наданими зразками.
- Усі ресурси локальні; немає аналітики, зовнішніх шрифтів, платіжних SDK чи збору даних.

## Обмеження демоверсії

Це **демонстрація інтерфейсу GivingFuel**, а не справжня форма чи iframe. Сайт не збирає платіжні дані, нічого не надсилає і не перенаправляє на оплату після надсилання форми. Окремі посилання Venmo, PayPal та Cash App тепер ведуть на справжні зовнішні сторінки сервісів. Надане посилання збережено лише в інструкції нижче. Перемикач суми не впливає на GivingFuel.

У хедері та як favicon (іконка вкладки) використовується наданий `assets/logo-header.png`, у футері — `assets/logo-footer.png`. Обкладинка через `<picture>` автоматично обирає `assets/cover-mobile.png` для ширини до 760 px і `assets/cover-desktop.jpg` для більших екранів. Використовуються оригінальні файли без редагування; кадрування задає CSS. Перед запуском підтвердьте права на використання матеріалів. Старі SVG-заглушки залишено як невикористані ресурси. Доступні англійська (`/en/`), українська (`/uk/`) і російська (`/ru/`); коренева сторінка англійською. Перемикач у хедері використовує звичайні посилання та працює без JavaScript. Статистика, 25 років роботи та твердження про вплив взяті з макета і потребують підтвердження організацією. Юридичні сторінки ще не підготовлені.

## Архів для хостингу

Виконайте `python3 scripts/package.py` з каталогу проєкту. Буде створено `dist/imoce-donation-demo.zip`. Архів і скриншоти генеруються локально й не зберігаються в Git.

## Завантаження на HOSTiQ — лише після окремого дозволу

**У цьому завданні сайт не завантажувався і не публікувався.**

1. У панелі HOSTiQ відкрийте cPanel → «Диспетчер файлів» (назви можуть відрізнятися залежно від тарифу).
2. Знайдіть кореневий каталог потрібного домену: часто `public_html`, для додаткового домену шлях перевірте в розділі «Домени». Спершу створіть резервну копію наявного сайту. Не перезаписуйте існуючі файли без перевірки.
3. Для першої перевірки використайте окремий тестовий підкаталог. Завантажте `dist/imoce-donation-demo.zip` і розпакуйте **вміст** у потрібний каталог. `index.html`, `styles.css`, `app.js`, `locales.js` та папки `assets`, `en`, `uk`, `ru` мають лежати разом, без зайвої вкладеної папки. Видаліть ZIP із публічного каталогу після розпакування.
4. Не завантажуйте `.git`, `tests`, `artifacts`, README чи залежності. PHP, Node.js та база даних сайту не потрібні.
5. Для публічного запуску ввімкніть SSL для домену засобами HOSTiQ і перевірте HTTPS. До схвалення тримайте тестовий каталог закритим паролем через панель хостингу: непублічне посилання саме по собі не є захистом.
6. Перевірте на телефоні та ПК: зображення, вибір сум, Other, помилку для 0, Monthly / One-time, усі демокнопки, Escape та масштабування. Форма GivingFuel має показувати тільки демоповідомлення. Venmo, PayPal і Cash App відкривають надані власником зовнішні сторінки; перевірте правильність акаунтів, не здійснюючи платіж.

### Майбутнє підключення платежів — окреме завдання

Наданий власником URL: `https://imoce.givingfuel.com/safe-shelter-for-girls-in-west-pokot`.

Перед підключенням підтвердьте відповідність цієї кампанії загальним текстам про освіту/харчування: URL стосується притулку для дівчат у West Pokot. Отримайте офіційний embed-код GivingFuel або погодьте просте зовнішнє посилання. Не вигадуйте параметри суми чи регулярності і не вбудовуйте сторінку через iframe без перевірки підтримки. Зберігайте платіжні поля тільки на стороні платіжного провайдера.

Посилання Venmo, PayPal, Cash App, соцмережі та сайт організації вже підключені за адресами власника. Потрібні затверджені Privacy / Donation policy, підтверджені цифри та погодження наданих логотипів і фотографій. Після окремого схвалення замінити демовзаємодії, перевірити sandbox провайдерів і лише тоді прибрати DEMO-позначки. Ніякі секрети не вставляти у HTML/JS.

## Автоматична перевірка

`tests/smoke.cjs` використовує Playwright та Chromium (це лише інструменти тестування, на HOSTiQ не потрібні). Запустіть сервер вище, потім `node tests/smoke.cjs` у середовищі з Playwright. Шлях до Chromium за потреби задайте через `CHROMIUM_PATH`.

Перевіряються ширини 320, 390, 768, 1440 px, сума, періодичність, валідація, усі заглушки, діалоги, горизонтальне прокручування, помилки JavaScript та відсутність зовнішніх запитів. Знімки поточного запуску зберігаються в `artifacts/`.

## Мови та редагування

Редагуйте структуру в `templates/index.html`, переклади — у `translations/en.json`, `translations/uk.json`, `translations/ru.json`. Виконайте `python3 scripts/build_languages.py`, потім `python3 scripts/package.py`. Генерація не потребує сторонніх бібліотек. Згенеровані HTML і `locales.js` зберігаються в Git, тому HOSTiQ не потребує Python.

Завантажуйте також `locales.js` і папки `en`, `uk`, `ru` з архіву, зберігаючи структуру. Усі мови використовують спільні CSS, JS та зображення. Посилання відносні, тому сайт працює і в підкаталозі. Статичний текст доступний без JavaScript; для демоформи потрібен JavaScript. Валюта в усіх мовах — долар США; змінюється лише формат показу, а не сума чи валюта платежу. Мова майбутнього зовнішнього GivingFuel checkout потребує окремого налаштування. Перед запуском погодьте переклади та юридичні тексти.

Перевірка мов: `node tests/languages.cjs` (після запуску локального сервера). Вона перевіряє три мови на чотирьох ширинах, усі переходи між мовами, повідомлення форми та сторінки без JavaScript. У перемикачі українська позначена UA, у HTML та URL використано стандартний код `uk`.

Перевірка зовнішніх посилань: `node tests/links.cjs`. Навігація перехоплюється тестом, тому перевіряються точні URL і відкриття нової вкладки без запитів до платіжних акаунтів. Це не перевірка власника акаунтів або приймання платежів.
